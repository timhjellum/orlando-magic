Built for the Orlando Magic front office, the Scouting Application replaces scattered spreadsheets and paper files with a single SharePoint tool for tracking prospects, filing scouting and injury reports, and building draft-day player lists. The work spanned the full arc of the project — from the first whiteboard session to the pixels that shipped.

Responsibilities included facilitating brainstorming and requirements-gathering sessions with scouts and front-office staff, producing creative and interactive design comprehensives, and building a high-fidelity, click-through prototype to pressure-test the workflow before a line of production code was written.

On the build side, that meant delivering master pages, page layouts, and web parts styled and scripted with CSS, jQuery, Bootstrap, and Knockout — matched against persona development, information architecture, search optimization, and responsive design done up front, so every screen served an actual scout's actual workflow.

Approach

Prototype to Production

High-fidelity prototypes were built on a responsive grid and run through formative testing against the front office's most complex real-world use cases — building a draft board under time pressure, filing an urgent injury report, cross-referencing a scout's notes against a player's college stats — before any design was considered final.

The brief was to deliver highly usable, efficient solutions with a genuinely responsive interface, and to hold every layout, web part, and app to pixel-perfect execution against the Magic's existing design standards and branding requirements.
